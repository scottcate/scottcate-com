Intellisence is great. It shows us a lot, and mostly at the perfect time. When parameter info is being displayed in a tooltip, did you know you can copy or paste this information? This video trick shows you how.

**_\[CTRL\]+\[ALT\]+\[SHIFT\]+\[P\]_** Paste the default parameter names directly into the function.

**_\[CTRL\]+\[ALT\]+\[SHIFT\]+\[C\]_** Copy the info for some other line (see the commented line in the picture.  Copying the parameter info will put the function name and all parameter information onto the clipboard.)

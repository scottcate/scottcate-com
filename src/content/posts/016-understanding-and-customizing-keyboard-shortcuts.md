Visual Studio has a ton of Keyboard shortcuts built in. In fact, there are HUGE PDF Prints available for VS2005 C# and Visual Basic, as well as VS2008 C# and VS2008 Visual Basic. If you want to change or add to the current keyboard shortcuts, this video shows you how.

[Visual Studio 2010 Keyboard Shortcuts for Download (Microsoft)](http://www.microsoft.com/en-us/download/details.aspx?id=13189)

[Massive List of 2012 Predefined Keyboard Shortcuts for VS2012 (Microsoft)](http://msdn.microsoft.com/en-us/library/da5kh0wa.aspx)

One of the first custom keyboard shortcuts I add is _**\[CTRL\]+\[ALT\]+\[P\]**_. This shortcut isn’t used for anything, so I’m not overriding anything built in, but I bind it to “Debug.AttachToProcess” which is much faster than navigating to _**Debug | Attach to Process**_.

On the Tools – Options – Text Editor – File Extension page, you can map a file extension to one of the included editors. 

[![Mapping a file extension .sara to an editor](http://blogs.msdn.com/blogfiles/saraford/WindowsLiveWriter/Did.Howtogetsyntaxhighlightingforagivenf_E88A/FileExtensionMapping1_thumb.jpg)](http://blogs.msdn.com/blogfiles/saraford/WindowsLiveWriter/Did.Howtogetsyntaxhighlightingforagivenf_E88A/FileExtensionMapping1_2.jpg)

And after mapping the .sara extension to a C# editor, we now get syntax highlight…

[![.sara file with C# syntax highlighting](http://blogs.msdn.com/blogfiles/saraford/WindowsLiveWriter/Did.Howtogetsyntaxhighlightingforagivenf_E88A/FileExtensionMappingSaraExtension_thumb.jpg)](http://blogs.msdn.com/blogfiles/saraford/WindowsLiveWriter/Did.Howtogetsyntaxhighlightingforagivenf_E88A/FileExtensionMappingSaraExtension_2.jpg)

There is also an option to map files without extensions to a specific editor.

[![Mapping extensionless files to an editor](http://blogs.msdn.com/blogfiles/saraford/WindowsLiveWriter/Did.Howtogetsyntaxhighlightingforagivenf_E88A/FileExtensionMapping2_thumb.jpg)](http://blogs.msdn.com/blogfiles/saraford/WindowsLiveWriter/Did.Howtogetsyntaxhighlightingforagivenf_E88A/FileExtensionMapping2_2.jpg)

No doubt you’ve seen how Visual Studio can dock tool windows in al kids of cool patterns, floating, docked, tabbed, etc. Did you know you can grab and move these tool windows with the keyboard?

**_\[ALT\]+\[MINUS {-}\]_** = Show Tool Window Move Menu

**_\[ALT\]+\[F6\]_** = Toggle Forward through all open Tool Windows

**_\[CTRL\]+\[PgDn\]_** = Move Right through tab groups in Tool Window

**_\[CTRL\]+\[PgUp\]_** = Move Left through tab groups in Tool Window

**_\[SHIFT\]+\[F6\]_** = Toggle Backwards through all open Tool Windows

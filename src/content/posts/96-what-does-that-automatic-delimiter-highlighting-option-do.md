Honestly, I had to ask around what this one did.  I couldn’t remember to save my life.

Automatic Delimiter Highlighting

[![Automatic Delimiter Highlighting Tools Option](http://blogs.msdn.com/blogfiles/saraford/WindowsLiveWriter/Did.WhatdoesAutomaticDelimiterhighlighti_BEC5/automaticDelimiterHighlightingOption_thumb.jpg)](http://blogs.msdn.com/blogfiles/saraford/WindowsLiveWriter/Did.WhatdoesAutomaticDelimiterhighlighti_BEC5/automaticDelimiterHighlightingOption_2.jpg)

Whenever you have code construct pairs (that’s what the documentation calls them), when you finish typing either the start or end pair, both pairs of words will become bold.  To turn off this feature, go to Tools – Options – Text Editor – General

![code construct pairs highlighted](http://blogs.msdn.com/blogfiles/saraford/WindowsLiveWriter/Did.WhatdoesAutomaticDelimiterhighlighti_BEC5/automaticDelimiterHighlighting_thumb.jpg)

Customizing the Automatic Delimiter Highlighting

You can customize the color for the bolding by going to Tools – Options – Fonts and Colors and selecting Brace Matching (Highlight).

[![Brace Matching fonts and colors option set to red](http://blogs.msdn.com/blogfiles/saraford/WindowsLiveWriter/Did.WhatdoesAutomaticDelimiterhighlighti_BEC5/automaticDelimiterHighlightingFontColors2_thumb.jpg)](http://blogs.msdn.com/blogfiles/saraford/WindowsLiveWriter/Did.WhatdoesAutomaticDelimiterhighlighti_BEC5/automaticDelimiterHighlightingFontColors2_2.jpg)
